# Finalização

## Como vou aplicar no meu código/projeto

1. **Antes de desenvolver uma nova feature no Flutter**, vou registrar o problema, o objetivo do usuário, as telas envolvidas e o fluxo principal. Só depois vou partir para implementação ou refinamento visual.

2. **Vou usar IA como parceira de preparação**, pedindo alternativas de estrutura, textos, estados de tela e organização de conteúdo, mas vou revisar cada sugestão antes de incorporá-la ao projeto.

3. **Vou separar estrutura de acabamento**: primeiro vou validar o fluxo com uma versão simples; depois vou trabalhar hierarquia visual, componentes, consistência e detalhes.

4. **Vou transformar protótipos importantes em fluxos navegáveis antes de codar tudo**, usando esse protótipo como uma etapa de verificação. Assim eu tento descobrir problemas de experiência antes de transformar uma decisão ruim em código difícil de desfazer.

## Minha mudança de mentalidade

A principal mudança que eu levo desta aula é parar de enxergar Figma como apenas uma ferramenta para desenhar telas. Eu posso usar o protótipo como uma extensão do meu raciocínio de produto: primeiro organizo o problema, depois torno a solução visível, testo o fluxo e só então invisto pesado na implementação.

No meu contexto de desenvolvimento, a IA entra como acelerador desse ciclo — não como substituta do meu julgamento técnico e de produto.
