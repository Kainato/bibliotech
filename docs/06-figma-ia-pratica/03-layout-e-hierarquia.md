# Layout, consistência e hierarquia visual

## O que eu aprendi

Aprendi que transformar a estrutura em layout não é simplesmente "deixar bonito". Eu preciso estabelecer uma hierarquia visual que ajude o usuário a perceber rapidamente o que é mais importante, o que pode ser feito e o que é informação de apoio.

Na prática, eu devo pensar em consistência entre telas: elementos que têm a mesma função devem parecer e se comportar de forma semelhante. Isso reduz a quantidade de decisões que o usuário precisa tomar e também facilita a manutenção do próprio arquivo de design.

A sequência que faz mais sentido para mim é:

**estrutura → hierarquia → componentes → detalhes visuais.**

## Como eu aplico

No Figma, eu começo definindo uma base visual simples e reutilizável. Depois organizo cada tela mantendo padrões de espaçamento, posicionamento, títulos, ações e componentes.

Eu também verifico cada tela perguntando:

- O que o usuário deve perceber primeiro?
- A ação principal está evidente?
- Existe informação competindo com ela?
- Elementos semelhantes continuam semelhantes entre as telas?

## Trade-offs & pegadinhas

**Consistência não significa deixar tudo idêntico.** Elementos iguais devem manter padrões; elementos com funções diferentes precisam ter diferenças perceptíveis.

**Eu não devo adicionar elementos só para preencher espaço.** Espaço vazio também organiza a informação.

**Detalhe visual não deve esconder prioridade.** Um efeito pode chamar atenção, mas isso não significa que ele seja importante para a tarefa.
